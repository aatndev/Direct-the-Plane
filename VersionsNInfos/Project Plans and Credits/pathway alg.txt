PATH ALG 
--------
Start ->
real path prefab will form
new path prefab will form to new path - tilting acc to the direction of real path & z+=10 

When player collide with real path ->
real path prefab goes to new path's position
new path prefab gets destroyed
new path prefab forms - tilting acc to the direction of real path & z+= 10

when plane z position is 100 -> everything will come back to z = 0
